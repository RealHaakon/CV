# MyAmazingESP32

A custom **ESP32 development board**, designed from scratch and made by me, inspired by
[Robert Feranec's hardware design course](https://www.youtube.com/watch?v=KWIzhbQaZZk).

- **Repository:** [MyAmazingESP32](https://github.com/realhaakon/MyAmazingESP32)
- **Updated:** September 5, 2026

## About

This board was built while learning the full hardware design flow: schematic capture,
PCB layout, and manufacturing files. It is my first complete, standalone development board.
