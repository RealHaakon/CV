# INF202 Oil Spill Simulation

**Bay City oil spill simulation** — course project for INF202: Advanced Programming (January 2026).

## About

A numerical simulation of oil trajectory and spread forecasting in Bay City, developed as a
group project (Group 18) at NMBU. The simulation models oil spill dynamics using computational
meshes, with configurable parameters for time steps, duration, and geometry.

Built with **Python**, featuring a modular architecture with packages for geometry, simulation,
and input/output handling.
