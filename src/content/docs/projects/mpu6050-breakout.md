# MPU6050 Breakout

My first breakout board, using the **MPU6050** inertial measurement unit (IMU) sensor.

- **Repository:** [MPU6050-Breakout](https://github.com/realhaakon/MPU6050-Breakout)
- **License:** MIT
- **Updated:** August 1, 2026

## About

A simple breakout board routing the MPU6050's I2C and power pins to convenient headers.
The project builds on the pinout and decoupling fundamentals learned from earlier hardware work.
